# Effective factors

One folder per book combination of the thesis' union analysis. Each
folder contains the k = ceil(N_eff) representative factors selected
by pivoted QR / pivoted Cholesky on the correlation matrix of the raw
fit-window signals (missing cells as zero, fit window < 2021-07-20 --
the exact convention behind every published N_eff of the thesis), with
selection rank in the file name and details in the per-folder
README. Generated by scripts/build_effective_factors.py;
deterministic given the signal store.

The N_eff values quoted in the folder READMEs are the published thesis
values, and k = ceil(N_eff) of these. A recomputation with
scripts/build_effective_factors.py reproduces them to two decimals for
every set except the 101 alphas alone (8.2 recomputed vs 7.6 published,
a small vintage/numerics tolerance); both values are recorded in
selection_summary.json.
